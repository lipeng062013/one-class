# 嘉壹启航 · 米金轻奢 UI 美化设计

**日期：** 2026-07-29  
**状态：** 已确认（色调 I；其余项按推荐默认）

## 1. 目标

在不改业务功能的前提下，把运营平台前端从默认 Element 蓝灰，调整为 **简约 · 素雅 · 正式 · 轻奢** 的视觉气质。

用户确认：

- 主色气质：**I · 米金轻奢**
- 后续未决选项：全部采用推荐默认
- 完成后：**提交并上传代码到 GitHub**

## 2. 色板（锁定）

| Token | 色值 | 用途 |
|-------|------|------|
| `--oc-sidebar` | `#292524` | 侧栏 / 深色壳 |
| `--oc-sidebar-text` | `#e7e5e4` | 侧栏次级文字 |
| `--oc-gold` | `#f5e6c8` | 品牌字 / 激活高亮 |
| `--oc-primary` | `#a16207` | 主按钮 / 链接 / 强调 |
| `--oc-page` | `#faf8f3` | 页面底 |
| `--oc-card` | `#fffdf8` | 卡片底 |
| `--oc-border` | `#e8e0d0` | 边框 |
| `--oc-ink` | `#44403c` | 主文字 |
| `--oc-muted` | `#78716c` | 次级文字 |

Element Plus 主色映射为 `--oc-primary`（`#a16207`），并补齐 light/dark 衍生色。

## 3. 推荐默认（用户授权自动采用）

| 项 | 推荐 | 说明 |
|----|------|------|
| 改动范围 | **主题 token + 壳层 + 登录 + 工作台** | 业务页继承 primary，不逐页重做表单 |
| 布局 | **保持现有侧栏 + 顶栏** | 不改信息架构与路由 |
| 圆角 | **8–10px** | 克制、偏品牌，不玩具感 |
| 密度 | **舒适** | 主区内边距 16–20px |
| 字体 | **现有系统字体栈** | 只调字重与层级 |
| 侧栏菜单 | **深石底 + 米金激活** | 与色板一致 |
| 登录页 | **米白暖渐变 + 金按钮** | 与后台统一 |
| 老师端移动壳 | **同色系浅色顶/底栏** | 与运营端同一品牌 |

## 4. 实现方式

1. `frontend/src/style.css`：CSS 变量 + Element Plus 主色覆盖 + 通用卡片/页面基调  
2. `AppLayout.vue`：侧栏、品牌、菜单、顶栏按米金轻奢重绘  
3. `MobileLayout.vue`：老师端壳层同步  
4. `LoginView.vue`：登录背景与卡片气质  
5. `DashboardView.vue`：统计卡与区块轻微抛光（阴影、圆角、边框）

**不做：** 重写业务表单逻辑、换 UI 框架、新增功能页。

## 5. 验收

- 登录页与工作台主色为琥珀金，非默认蓝  
- 侧栏为深石色，激活项米金可读  
- `npm run build` 通过  
- 代码提交并 push 到 GitHub remote
